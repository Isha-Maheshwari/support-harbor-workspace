# Support Harbor Workspace

Build a sophisticated, functional multi-page enterprise customer-support application named SupportDesk Pro using React, TypeScript, Vite, Tailwind CSS, shadcn/ui, React Router, and TanStack Query where useful for server state. Use a local asynchronous mock service with realistic seeded records, latency and controllable error states. No external credentials.

Implement EVERY route listed below as a distinct, functional page, not just sidebar links:
Workspace: /dashboard, /dashboard/analytics, /activity-log
Tickets: /tickets, /tickets/new, /tickets/:id, /tickets/:id/edit, /tickets/assigned, /tickets/escalations
Customers: /customers, /customers/new, /customers/:id, /customers/:id/edit
Knowledge base: /knowledge-base, /knowledge-base/new, /knowledge-base/:id, /knowledge-base/:id/edit
Team and SLA: /team, /team/:id, /sla/policies, /sla/breaches
Reports: /reports, /reports/tickets, /reports/agents
